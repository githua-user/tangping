# tangping

 基本实现了躺平发育/猛鬼宿舍的全部要素

 期待完善更新
<br>

###  [在线试玩](https://githua-user.github.io/tangping/)


<br>
<br>


*   **核心框架**: React 
*   **开发语言**: TypeScript
*   **样式库**: Tailwind CSS
*   **渲染引擎**: HTML5 Canvas API 
*   **状态管理**: React Context 




**安装依赖**
```bash
npm install
```
 **启动服务器**
```bash
npm run dev
 ```
**构建生产版本**
 ```bash
npm run build
 ```
